## Introduction to Computers
A **computer** is an electronic device that accepts raw data as input, processes it using stored instructions, produces meaningful output, and stores the results for future use. 

Computers consist of two main components:
* **Hardware:** The physical parts such as CPU, RAM, and storage.
* **Software:** The programs and operating systems that direct the hardware.
